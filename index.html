שיחה - תוכנת דואר אישית

"שיחה" היא תוכנת דואר שפועלת על המחשב של המשתמש: תצוגת שיחות לפי אדם, תצוגת דואר רגילה, זיהוי דיבור בעברית ויומן.

התוכנה משתמשת ביומן של גוגל כדי להציג את הפגישות של המשתמש ולהוסיף פגישות שהוא מבקש. כל המידע נשמר רק במחשב של המשתמש.

Sicha Mail

Sicha Mail is a personal desktop email client that runs locally on the user's own computer. It offers a conversation view per person, a classic mail view, Hebrew speech recognition and a calendar view.

The app uses the Google Calendar API only to show the user's own events inside the app and to create events the user explicitly asks to add. All data stays on the user's computer.
