איזה מידע התוכנה מקבלת מגוגל

רק אחרי אישור של המשתמש: כתובת הדואר שלו (כדי לדעת לאיזה חשבון שייך היומן), והגישה לאירועים ביומן של גוגל.

מה התוכנה עושה עם המידע

  • מציגה את הפגישות של המשתמש בתוך התוכנה, במחשב שלו.
  • מוסיפה ליומן פגישה רק כשהמשתמש מבקש זאת במפורש.

שמירה ושיתוף

התוכנה פועלת כולה על המחשב של המשתמש. אין לה שרת חיצוני. המידע לא נשלח לאף גורם, לא נמכר, ולא משמש לפרסום. האישור שגוגל נותן נשמר מוצפן במחשב של המשתמש.

ביטול

אפשר לנתק את היומן בכל רגע מתוך הגדרות התוכנה, או בדף ההרשאות של חשבון גוגל: myaccount.google.com/permissions.

Privacy Policy - Sicha Mail

Last updated: October 19, 2026

Data accessed

Only after the user grants consent: the user's email address (to identify which account the calendar belongs to) and access to the user's Google Calendar events.

How the data is used

  • To display the user's own events inside the app, on the user's computer.
  • To create a calendar event only when the user explicitly asks for it.

Storage and sharing

The app runs entirely on the user's own computer and has no external server. Data is not transmitted to any third party, is not sold, and is not used for advertising. OAuth tokens are stored encrypted on the user's computer.

Sicha Mail's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Users can disconnect the calendar at any time from the app's settings, or at myaccount.google.com/permissions.
